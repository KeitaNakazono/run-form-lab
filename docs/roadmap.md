## Phase 1：動画 → 棒人間

- [ ] **1-1 動画の読み込みと再生**
  ファイル選択、再生／一時停止、コマ送り（±1フレーム）、0.25x〜1x 再生。fps 表示と手動修正。
  完了条件：iPhone Safari と PC Chrome で mp4 / mov を読み込める（できない形式はエラー表示）。
- [ ] **1-2 姿勢推定（Worker）**
  `@mediapipe/tasks-vision` の PoseLandmarker を Worker で実行。モデル・wasm は `public/` に置いて自前ホスト。進捗バー・キャンセル。
  完了条件：3秒の動画で全フレームの landmark が得られ、UI が固まらない。
- [ ] **1-3 棒人間の描画**
  実映像＋棒人間の重ね表示／棒人間のみ を切替。左右の脚を色分け。
  完了条件：再生・コマ送りに棒人間が追従する。

## Phase 2：計測の準備

- [ ] **2-1 信号処理ユーティリティ**（`core/signal`）
  欠損補間、ゼロ位相 Butterworth、微分。単体テスト付き（正弦波で検証）。
- [ ] **2-2 スケール設定**
  コーン2点タップ → px→cm。未設定時は脚長比。
- [ ] **2-3 地面ラインの推定**
  RANSAC で直線フィット、画面上で手動調整。
- [ ] **2-4 接地・離地の自動検出＋手動修正**
  [metrics.md §2](metrics.md)。タイムラインにマーカー、±1フレームで修正、保存。
  完了条件：合成データのテストで既知の IC / TO を ±1 フレーム以内で検出。

## Phase 3：指標

- [ ] **3-1 腰の上下動**：軌跡の描画、歩ごとの値、平均、グラフ。
- [ ] **3-2 着地位置**：接地フレームの垂線と距離の矢印、左右別の値。下腿角度。
- [ ] **3-3 補助指標**：ピッチ、体幹前傾、接地中の膝、接地タイプ（参考）、接地時間（120fps以上のみ）。
