# 指標の定義と計算方法

方針：**特殊な数値は出さない。** コーチが目で見て確認したい
「腰の上下動」「股関節の真下に近い接地か（オーバーストライド）」を、
**図（線・軌跡）＋ シンプルな数値** で示す。合否判定はしない（MVP）。
根拠は [research.md](research.md)。

## 0. 前提と座標系

- 姿勢推定：MediaPipe Pose Landmarker（33点）。使う点：

| 部位 | index（左 / 右） |
|---|---|
| 肩 | 11 / 12 |
| 股関節 | 23 / 24 |
| 膝 | 25 / 26 |
| 足首 | 27 / 28 |
| 踵 | 29 / 30 |
| つま先（foot index） | 31 / 32 |

- 画像座標：x 右向き、y 下向き（px）。計算はすべて **px で行い、表示時に cm へ換算**。
- **進行方向** `dir = sign(腰中点xの終了値 − 開始値)`（+1 右へ / −1 左へ）。前方距離はすべて `dir` を掛けて「前が正」にそろえる。
- **腰中点** `H = (左股関節 + 右股関節) / 2`。真横撮影では左右がほぼ重なるため、中点を骨盤（≒重心の代わり）として使う。
- **手前側の脚 / 奥側の脚**：landmark の `visibility` の平均が高いほうを手前側とする。奥側の脚は隠れやすいため、**指標は手前側の脚の接地を優先** し、奥側は visibility が閾値（初期値 0.6）以上のフレームのみ使う。
- **時間**：フレーム番号ではなく **実時間（秒）** で持つ。`t = frameIndex / captureFps`。
  `captureFps` は動画メタデータを初期値とし、ユーザーが確認・修正できる（スロー動画が30fpsに変換されている場合があるため。[filming-guide.md](filming-guide.md)）。

## 1. 前処理

1. **欠損処理**：visibility が低い点は欠損扱い。短い欠損（≤ 3フレーム）は線形補間、それ以上は区間を分割。
2. **平滑化**：2次 Butterworth ローパスを前後方向に適用（ゼロ位相、filtfilt 相当）。
   カットオフ初期値 **6 Hz**（論文では 4〜7.5 Hz の範囲）。設定で変更可。オフライン処理なのでゼロ位相にできる。
3. **スケール（px → cm）**：
   - 第1候補：画面上でコーン2点をタップ → 既知距離（初期値 200 cm）で `cmPerPx` を求める。
   - 第2候補：身長入力 → 立位フレームが無いので **脚長（股関節〜足首の平均 px）× 比率** で概算（精度低、と表示）。
   - スケール未設定でも、**脚長に対する % 表示** は常に出せる。
4. **地面ライン**：各足の最下点 `F = 踵とつま先のうち y が大きい方` について、接地中と思われるフレーム（局所的な y 最大付近）の点群に直線をフィット（RANSAC 推奨）。カメラのわずかな傾きを吸収する。以降「高さ」は地面ラインからの距離で扱う。

## 2. イベント検出（接地・離地）

各足について：

- **接地（IC: initial contact）**：足の最下点 `F` の地面ラインからの高さが閾値以下に入り、かつ鉛直速度が「下向き → ほぼ 0」に変わった最初のフレーム。
- **離地（TO: toe-off）**：つま先の高さが閾値を超えて上昇し始めた直前のフレーム。
- 閾値初期値：脚長の 2%（設定可）。
- **手動修正 UI 必須**：自動検出の結果をタイムライン上に表示し、ユーザーが ±1 フレーム単位で動かせる。修正値を保存して以降の計算に使う。
- **検出の信頼性**：`captureFps < 100` のときは「接地の瞬間がずれている可能性」バッジを表示。

## 3. メイン指標

### 3.1 腰の上下動（vertical oscillation）

- 定義：1歩（IC → 次の反対足 IC）ごとの `H.y` の最大 − 最小（＝最高点と最低点の差）。
- 表示：
  - **映像上**：腰中点の軌跡（波線）を重ねて描く。最高点・最低点にマーカー。
  - **数値**：平均値（cm、スケール未設定なら脚長比 %）、歩ごとのばらつき。
  - **グラフ**：時間 × 腰の高さ。IC の位置に縦線。
- 注意：腰中点は重心そのものではない（目安）。比較は同じ人・同じ撮影条件で行う。

### 3.2 着地位置（オーバーストライド／股関節の真下に近い接地か）

- 定義：IC フレームでの **足の接地点の、腰中点からの前方水平距離**
  `D = dir × (F_ic.x − H_ic.x)`（正＝体より前に着地）。
  接地点 `F_ic` は踵とつま先のうち先に地面に着いた方（判定不能なら足首）。
- 表示：
  - **映像上**：IC フレームで静止し、腰中点から **真下への縦線（垂線）** と接地点を描く。両者の間に距離の矢印。←「股関節の真下にどれだけ近いか」を一目で見せるのがこのアプリの核。
  - **数値**：D（cm または脚長比 %）、左右別・歩ごと・平均。
- 補助：**接地時の下腿角度**（膝→足首の線が鉛直となす角、前傾が正）。Folland 2017 で記録と関連。0°に近いほど「足が体の下に着いている」状態。

## 4. 補助指標（シンプルに表示）

| 指標 | 定義 | 備考 |
|---|---|---|
| ピッチ（歩/分） | 60 / 連続するIC間隔の平均 | 実時間で計算。fps 誤りに注意 |
| 体幹前傾 | 肩中点−腰中点の線が鉛直となす角（前が正）、歩ごとの平均 | |
| 接地中の膝の曲がり | IC〜TO 間の膝角度の最小値（股−膝−足首の角） | 角度誤差 5〜11° を考慮し「目安」 |
| 接地タイプ（参考） | IC 時の踵とつま先の高さの差・足部角度から 踵 / 中足部 / 前足部 | **評価しない、参考表示のみ**。research.md §2 |
| 接地時間（参考） | TO − IC | `captureFps ≥ 120` のときだけ表示 |

## 5. 比較（2画面・重ね合わせ）

- **同期**：両セッションの「手前側の脚の IC」を基準に頭出しし、実時間で同期再生（片方がスロー動画でも実時間でそろう）。
- **棒人間の重ね合わせ**：腰中点を原点に平行移動し、脚長で正規化（体格差を消す）。進行方向をそろえる（左右反転）。
- **数値の差**：メイン指標の差分（前回比）を表示。

## 6. 表示しないもの（MVPの方針）

- 「良い / 悪い」の判定、点数、ランク付け。
- エリート選手の値との比較基準値（根拠となる統一値がないため）。
- 3D 指標、関節モーメントなどの力学量。

## 7. テスト方針

- 指標の計算はすべて **純粋関数**（入力：landmark 時系列＋設定 → 出力：イベント・指標）。
- テストデータは **合成データ**（正弦波で腰を上下させる、既知位置で足を接地させる 等）で期待値を作る。実際の人物動画はリポジトリに入れない。
