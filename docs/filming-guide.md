# 撮影ガイド（アプリ内表示の元原稿）

アプリの「撮影ガイド」画面と、解析前チェックの文言はここを元にする。
根拠は [research.md §5](research.md#5-論文の撮影方法このアプリの撮影ガイドの根拠)。

## 必須

1. **カメラを固定する**（三脚・ベンチなど）。手持ち・追いかけ撮影は不可。
   パン（首振り）すると上下動・着地位置が正しく出ない。
2. **真横から撮る**。走る線に対してカメラを直角に向ける。
3. **スロー撮影（120fps 以上、できれば 240fps）**。
   30fps だとコマの間隔が約33msあり、接地の瞬間を取り逃がす。
4. **画面の中を走り抜けてもらう**。画面の左右どちらかから入って反対へ抜ける。
   助走で一定ペースになってから画面に入ること。
5. **全身（頭〜つま先）が写る**。足先が画面の下端で切れないように。

## 推奨

| 項目 | 推奨 | 理由 |
|---|---|---|
| 距離 | 走る線から 5〜8 m | 近すぎると遠近の歪み、遠すぎると関節がつぶれる |
| 高さ | 腰の高さ（約 0.8〜1.0 m） | 全身の比率が正しく写る。※接地の判定だけ厳密に見たい場合は低め（0.15〜0.3 m）も可 |
| 画角 | 標準（1x）。広角・超広角は使わない | 画面端の歪みで角度がずれる |
| 距離の目印 | 走る線上に **2 m 間隔でコーン2つ**（またはライン） | px→cm 変換に使う。コーンはランナーと同じ線上に置く |
| 背景 | 人が映り込まない、ランナーと背景のコントラストがある | 姿勢推定の誤認識を防ぐ |
| 服装 | 体の線がわかる服。だぼっとした服・長いパンツは避ける | 関節位置の推定精度 |
| 本数 | 同じ条件で 2〜3 本 | 1本だけだと偶然の1歩に引っ張られる |
| 記録 | 撮影日、場所、ペース、シューズ、撮影fps | 比較のときに条件をそろえるため |

## 比較するときの注意

- **トレッドミルとグラウンドの映像は比較しない**（足の角度・上下動が変わる）。
- 速度が違うと上下動・歩幅は当然変わる。**同じくらいのペース同士で比較**する。
- シューズが違うと接地は変わる。

## スマホ別メモ（実装時に検証して追記）

- iPhone：設定 → カメラ → スロー撮影 で 120/240fps を選ぶ。
  「写真」アプリから共有するとき、スロー再生に変換された 30fps 動画になることがある → アプリ側で **撮影fps を確認・入力** させる。
- Android：機種により「スローモーション」の保存形式が異なる。要検証。
